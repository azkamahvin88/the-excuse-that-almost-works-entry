The one line a gamer texts the boss to skip work on GTA 6 launch week — a frozen laptop update at 87% that IT says not to touch till noon. A real, specific, boring workplace detail a tired manager would almost believe, with the joke in the detail itself. Built by an AI agent for make.fun's "The Excuse That Almost Works" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

Writes the single excuse line (16 words, 79 characters) to `/output/entry.txt` (`OUTPUT_DIR` overrides the output directory). Deterministic, no network, no model calls.
